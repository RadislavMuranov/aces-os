# ACES OS — MANIFESTO

**Status:** PROPOSED / STRATEGIC NORTH STAR
**Version:** 2.0-proposed
**Date:** 2026-08-31

## We are not building another place to work.

The Digital World already has places for almost everything.

Documents have owners.
Code has owners.
Communication has owners.
Projects have owners.
Knowledge has owners.
Money has owners.

The problem is not the absence of places.

The problem is the space **between** them.

## The Digital World is becoming agent-native.

Software is changing again.

Natural language is becoming a programming interface.
LLMs are becoming a computational substrate.
Agents are becoming a new class of software actor.
Autonomy is moving from a binary choice toward a continuum.

The consequence is profound:

The Digital World must no longer be designed only for humans and conventional programs.

It must become usable by agents.

And humans need a way to remain in control of that transition without becoming its integration layer.

## ACES is the connector.

> **ACES OS — мой самый дружественный КОННЕКТОР с ЦИФРОВЫМ МИРОМ.**

The connector is not another destination.

It is the layer that makes destinations work together while remaining destinations.

The human should not have to remember:

- where the information lives;
- which system owns the action;
- what changed in another system;
- which context must be reconstructed;
- which permission is required;
- which agent can safely act;
- what has already been done;
- what remains uncertain.

ACES should carry that burden.

## Human → Agent → Digital World

ACES sits between human intention, agent capability, and digital execution.

`HUMAN ↔ ACES ↔ AGENTS ↔ DIGITAL WORLD`

The human supplies meaning, judgment, values, and legitimate authority.

Agents supply scalable cognition and execution.

The Digital World supplies the real systems where things actually happen.

ACES supplies continuity, context, coordination, verification, provenance, and governance.

## We reject the false choice.

Not:

`human OR agent`

Not:

`centralized ACES workspace OR fragmented tools`

Not:

`full autonomy OR no autonomy`

Instead:

`human + bounded agents + existing digital owners + trusted coordination`

## Capability is not authority.

A powerful model is not an authority.

A successful API call is not a decision.

A coherent answer is not evidence.

A generated artifact is not an accepted state.

ACES exists to preserve these boundaries.

## Autonomy must be earned.

We want agents that can act.

But action must be proportional to:

- demonstrated capability;
- empirical reliability;
- risk;
- scope;
- policy;
- authority;
- verification availability.

Autonomy is a slider, a contract, and a governance decision—not a marketing claim.

## Verification is the bridge to trust.

Agents generate.

Systems verify.

Humans decide where human judgment is required.

ACES records what happened and why.

The loop is:

`GENERATE → VERIFY → ACCEPT → REMEMBER → LEARN`

This is how probabilistic intelligence becomes dependable infrastructure.

## Memory must outlive the model.

Models change.
Providers change.
Tools change.
Agents change.

Continuity must not.

ACES memory, knowledge, evidence, provenance, policy, and accepted state must remain portable across models and environments.

## The human must not maintain the machine connections.

This is our deepest design test.

If the human must repeatedly create, repair, reconcile, copy, paste, tag, route, or explain the same cross-system state, the connector has failed.

> **ACES removes parasitic friction.**

It does not remove necessary human judgment.

It removes the recurring integration work that machines can safely perform.

## We build for agents without abandoning humans.

Every important external system should become understandable to agents through explicit contracts:

`capability + context + state + permission + provenance + verification`

But every agent-native interface must remain subordinate to human agency and system ownership.

## We do not build a new digital world.

We connect the one that already exists.

We do not replace GitHub.
We do not replace Google.
We do not replace Obsidian.
We do not replace Kaiten.
We do not replace specialized domain systems.

We make them coherent.

## The global ambition

The world is moving from software that humans operate to software that increasingly operates on behalf of humans.

The missing layer is not another assistant.

It is a trusted connective layer that can understand where the human is, what matters, what is known, what is uncertain, which system owns the next action, which agent may act, and whether the resulting state can be trusted.

That is the space ACES intends to explore.

## Our test

We do not ask whether ACES is elegant.

We ask:

> **Does ACES measurably reduce the human work required to maintain continuity across the Digital World while preserving agency, ownership, security, uncertainty, provenance, and recoverability?**

If yes, build it.

If no, remove it.

If existing systems can do it, use them.

If an agent can do it safely, automate it.

If only a human can legitimately decide, preserve the human decision.

## The North Star

> **A human should be able to move through the Digital World as if it were one coherent environment, while the underlying systems remain independent, specialized, replaceable, and owned by their proper domains.**

That is the future ACES OS is built to test.

**ACES OS is not another world. It is the trusted connector to the world.

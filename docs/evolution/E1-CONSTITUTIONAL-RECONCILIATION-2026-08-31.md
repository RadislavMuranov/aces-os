### NEW/FORMALIZED PRINCIPLES

1. **Connector Primacy** — connector realization is the highest-priority ACES hypothesis.
2. **Capability–Reliability–Authority Separation** — model capability does not imply trust or authority.
3. **Governed Cognitive Action** — the atomic unit of consequential agent work is a governed state transition, not a prompt.
4. **Bounded Autonomy** — autonomy is an explicit, risk-sensitive contract.
5. **Agent-Native Contract** — external systems must be consumable through machine-readable capability/context/state/permission/provenance contracts where feasible.
6. **Context Continuity** — reconstructable cross-system context is a primary connector capability.
7. **Artifact-Mediated Autonomy** — intermediate artifacts may be required between generation and consequential execution.
8. **Model-Independent Continuity** — memory, knowledge, evidence, authority and accepted state must survive model/provider replacement.
9. **Strategy Promotion Control** — learned strategies are candidates until evidence and evaluation justify promotion.

## 3. Constitutional conflicts resolved

### Conflict A — Connector vs Workspace

**Resolution:** Connector wins. A new workspace is permitted only when proven necessary to expose connector state or protect human comprehension.

### Conflict B — Agent capability vs authority

**Resolution:** Authority is never inferred from model identity, benchmark performance, API access, or agent confidence.

### Conflict C — Autonomy vs human primacy

**Resolution:** Human primacy is preserved through explicit authority contracts, scopes, policies, verification and revocation. Bounded autonomy is compatible with human primacy when legitimate delegation is explicit.

### Conflict D — Learning vs Canon

**Resolution:** Learning creates candidates. Canon requires a separate promotion gate.

### Conflict E — Strategic priority vs evidence discipline

**Resolution:** P0 means “most important hypothesis to prove,” not “assumed true.” Evidence Before Architecture remains constitutional.

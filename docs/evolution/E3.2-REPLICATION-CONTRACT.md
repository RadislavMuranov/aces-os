## 3. Workflow / task

**Task ID:** `e32-pr-drive-continuity-001`

**Definition:** Reconstruct continuity of ACES corpus-freeze / branch-protocol readiness across open GitHub pull requests and related Google Drive canon documents, producing an explicit decision-ready context that preserves provenance, conflicts, and unknowns.

**Starting state (observed class):**

- Open draft PR #1: `chore(corpus): freeze ACES source corpus registry`
- Open draft PR #2: `evolution: activate Branch Protocol`
- Drive document: `ACES OS — AGENT SCAFFOLDING EVOLUTION CANON (v1.0 Canonical)` (and related ACES docs if retrieved)
- No shared authoritative continuity store between GitHub and Drive

**Success state:**

An operator can state, with explicit provenance:

1. which PRs are open/draft and what each claims;
2. which Drive documents are relevant and their stated status;
3. any conflicts or unknowns (e.g. binary archive upload gap, draft vs ready-for-review, base SHA drift);
4. that no merge/write was performed (read-only).

**Verification method:** Independent review of evidence records against live source object IDs (PR numbers, Drive file IDs).

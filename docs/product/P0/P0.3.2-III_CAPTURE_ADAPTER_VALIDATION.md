## 1. Scope

Implement and validate a privacy-safe, scoped capture adapter enforcing allow-list, pause, provenance separation, explicit missing events, no unrestricted surveillance, tagged coordinator channel, no network transmission.

## 2. Architecture

SurfaceAllowList -> CaptureAdapter -> CaptureEvent stream
- observe_human (caller-attributed)
- emit_coordinator (tagged channel)
- observe_system / observe_unknown_surface
- record_missing
- compute_hcc_from_capture (human eligible only)

Adapter never infers actor from generic software events.

## 3. Privacy boundary

Hard allow-list; non-listed -> insufficient. Clipboard: hash only. No keylogging, no screen recording, no network, no file/body reads. Pause outside allow-list.

## 4. Capture mechanisms

Logical observation APIs implemented for all targets. Automatic OS focus/clipboard/window capture: NOT VALIDATED (headless environment lacks capability).

## 5. Provenance model

actor mandatory. primary_analysis_eligible only for human + allow-listed + HCC count type + sufficient confidence. Coordinator/system/unknown: never eligible.

## 6. Event schema

CaptureEvent + MissingEvent in src/p0_capture/schema.py.

## 7. Validation environment

Linux headless sandbox, Python 3.12, pytest. No desktop session, no accessibility bus, no real browser profile.

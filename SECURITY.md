# Security Policy

## Supported Versions

This repository is in early foundation stage. No released software versions exist yet.

## Reporting a Vulnerability

If you discover a security issue related to this repository:

1. Prefer GitHub private vulnerability reporting for this repository (if enabled by the owner).
2. Otherwise, open a private communication channel with the repository owner via GitHub (do not open a public issue containing exploit details).

Do **not** commit secrets, credentials, private keys, or tokens to this repository.

## Scope

This document covers repository-level security reporting expectations only.
It does not define ACES OS architecture, runtime security, or ASA threat models.
